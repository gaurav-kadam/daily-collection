# Daily Collection Frontend

React + Firebase frontend for the Daily Collection Management System.

## Stack

- React + Vite
- React Router
- Tailwind CSS
- Firebase Authentication
- Cloud Firestore
- Firebase Storage
- React Hot Toast
- React Icons

## Routes

- `/login`
- `/dashboard`
- `/customers`
- `/my-customers`
- `/collections`
- `/loans`
- `/emi-payments`
- `/notifications`
- `/settings`

## Setup

```bash
npm install
npm run dev
```

The default Firebase project config is defined in `src/firebase/firebase.js`.
